# C++ HTTP Server – From Scratch
Bare metal HTTP in modern C++. No frameworks. Just sockets, threads, and pure control.

This project is a clean, minimal HTTP/1.1 server implemented in modern C++ using low-level socket APIs. It's built from the ground up to deepen understanding of how web servers work under the hood, without any external libraries or frameworks.

🧩 Features:

Manual HTTP request parsing

Static file serving

Basic routing system

Multithreaded request handling

Error handling and logging

Benchmark-ready setup

Later, the project will be reimplemented in Rust to compare performance, safety, and developer experience.
